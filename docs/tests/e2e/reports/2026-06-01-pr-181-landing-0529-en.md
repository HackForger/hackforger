# PR #181 — 5.29 landing updates + English support (#180 + #179) — E2E smoke test

## What shipped

PR #181 (`feat(landing): 5.29 updates + English support`, merge
`5e9ea46d2c`) bundles two landing-page issues into one change. Single file:
`custom/public/assets/landing/index.html` (static asset, served from disk,
no `make` required).

**#180 — 5.29 content updates** (commits `d80cbcaabc`, `1a6b85b853`):

| Item | Before → After |
| --- | --- |

## Risk surface

Low — landing-page-only, single static-file change:
- No Go / template / binary / DB impact. `custom/public/` is served as static
  files and rsynced to the cloud by `deploy/ecs/redeploy.sh`.
- EN support is additive: a new `INFO_PAGES_EN["rule-full"]` entry plus an
  i18n string map; zh content paths are untouched (regression-confirmed).
- Rollback is trivial: re-deploy the previous landing HTML.

## Notes / minor observations

- agent-browser intermittently desynced its scripting context from the
  foreground tab mid-session; screenshots (which target the visible tab)
  and a clean-session re-open were used to obtain authoritative results.
  Not a product issue.
