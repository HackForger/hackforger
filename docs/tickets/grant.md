# Grant

## Feature Requests

### HF-018: Grant 批准需要通知
- **Priority**: High
- **Source**: E2E testing
- **Description**: Grant 申请被批准时，申请者应收到通知（站内通知 + 可选邮件）。当前批准操作没有触发任何通知。

### HF-019: Grant 预算和奖励金额显示应关闭编辑
- **Priority**: Medium
- **Source**: E2E testing
- **Description**: Grant Round 页面显示"预算: 10000 USD (已使用: 1)"，此处的已使用金额不应可编辑。管理面板中的奖励金额也应为只读状态。
