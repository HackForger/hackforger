# Feed & Notifications

## Feature Requests

### HF-022: 关注后添加通知
- **Priority**: High
- **Source**: E2E testing
- **Description**: 用户关注（Follow/Watch）Hackathon、Bounty、Grant 等实体后，相关状态变更应触发通知。当前关注操作不产生后续通知。

### HF-023: 组织"加入"按钮替代"关注"
- **Priority**: Medium
- **Source**: E2E testing
- **Description**: 当前组织页面禁用了"关注"逻辑。应添加"加入组织"按钮，点击后自动将用户加入组织的 Member Team。这比"关注"更符合 Hackathon 场景的语义。

### HF-024: 用户 Feed 优化
- **Priority**: Medium
- **Source**: GitHub #16
- **GitHub Issue**: HackForger/hackforger#16
- **Description**: 用户 Dashboard Feed 的右侧栏显示的仓库、组织信息因为 Hackathon 实体的绑定关系显得混乱。需要展示更多 Hackathon/Bounty/Grant 相关内容，可通过将相关 repo/org filter 出来，展示为"参与的黑客松/悬赏/赞助"等分类来改善。
