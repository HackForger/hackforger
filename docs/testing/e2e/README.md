# Neutral E2E templates

This directory contains reusable, business-neutral browser-test templates.

Concrete instance URLs, accounts, campaign fixtures, screenshots, reports, and
other runtime evidence belong in the corresponding access-controlled content
repository. Do not commit them to this public source tree.

Run real user-facing verification with `agent-browser`, and copy only generic
lessons or reusable test structure back into this directory after removing all
instance and customer context.
