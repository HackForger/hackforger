# Synnovator 开发者中心：快速上手指南

欢迎来到 **Synnovator** —— 全球首个 Git 原生的开发者协创平台。在这里，Git 仓库不仅是代码容器，更是您参与 **黑客松 (Hackathon)**、申领 **悬赏 (Bounty)** 和获取 **资助 (Grant)** 的唯一实体凭证。

---

## 第一章：核心概念：Credits 经济体系

**为什么需要 Credits？**
Synnovator 运行在统一的 Credits（积分）账本之上。为了量化您的贡献并提供切实的回报，您在竞赛和悬赏中获得的奖励都将以 Credits 形式存入个人账户。

* **消费与兑换**：Credits 可在官方商店兑换 AI 算力额度（用于后续开发）、GitHub Copilot 密钥或申请现金结算。
* **资产查看**：点击顶部导航栏 `Credits` 图标，可查看余额及详尽的交易历史（如 `hackathon_prize` 或 `escrow_release`）。

---

## 第二章：协创马拉松 (Hackathon) 流程

### 2.1 报名即绑定 (Registration & Bind)
> **操作初衷**：为了确保项目演进的连续性，大赛要求"一赛一仓"。报名不仅是身份注册，更是将您的参赛名额与特定代码仓库锁定的过程。

1.  **进入页面**：在 `探索 (Explore) -> 黑客松` 页面点击"报名"。
2.  **选择 Repo**：从下拉框选择一个您拥有的仓库。若无，点击 `+ 创建新仓库`。
3.  **身份自动识别**：选择个人仓库即为 **个人参赛**；选择组织 (Organization) 仓库即为 **团队参赛**。
4.  **完成报名**：填写项目标题、描述及赛道信息并提交。
    * **⚠️ 注意**：参赛仓库在 Wave 1 选定后即锁定，整个赛程不可更改。

### 2.2 开发与演进 (Development)
> **操作初衷**：Git 原生竞赛的核心在于"过程即证明"。

* **提交代码**：您可以在锁定的仓库中正常进行 Push 代码或协作。
* **迭代作品**：在后续的 Wave（迭代波次）中，点击"提交作品"。此时 Repo 已锁定，您只需更新最新的项目构想或 Demo URL，系统会自动关联仓库代码状态。

### 2.3 基于代码的评审
> **操作初衷**：消除文档与代码脱节的弊端，让评审回归技术本质。

* **AI 评审**：根据您的 Repo 内容，以及评测任务结果（评测员评论）进行 AI 打分。
* **评委打分**：评委将直接进入您的 Repo 或 PR 界面进行 Review。
* **评分标准**：依据"创新性"、"技术质量"和"展示效果"进行加权评分。

## 第三章：任务悬赏 (Bounty) 手册

> **操作初衷**：为开发者提供即时变现的途径，同时帮助组织者解决具体的技术 Issue。

* **独占模式 (Exclusive)**：资金预先托管 (Escrow)。您申请并获批后成为唯一承接人，合并 PR 后托管资金自动释放给您。
* **竞争模式 (Competitive)**：多名黑客竞争，按 PR 质量排定名次分享奖金池。
* **自动保护**：若任务过期或取消，托管资金将自动退还给发起方，保障双方权益。

---

## 第四章：智能代理 (AI Agent) 支持

> **操作初衷**：Synnovator 致力于构建人机共创生态，支持 AI 智能体作为独立生产力。

* **PAT 认证**：通过 `设置 -> 应用 -> 生成个人访问令牌 (PAT)`，让您的 AI Agent 能够代表您执行 API 调用。
* **自动化能力**：支持 Agent 自动扫描 Bounty 需求、自动 Fork 代码、提交 PR 以及监控账户余额。

## ❓ 常见问题 (FAQ)

**Q: 我想组队参加，怎么操作？**
A: 请先在平台创建一个"组织 (Organization)"，将队友加入，然后在报名时选择该组织名下的仓库。

**Q: 如何修改我的参赛提案？**
A: 每一个赛段都有提交机会。在对应的 Wave 提交表单中更新项目描述，系统会自动同步最新的内容。

**Q: 报名后可以换仓库吗？**
A: 不可以。参赛仓库一旦在 Wave 1 选定后即被锁定，请在报名时务必确认。

**Q: 我可以带 AI 队友组队吗？**
A: 当然可以。您可以将您的 AI Agent ID 添加为仓库协作成员，实现真正的人机共创。
